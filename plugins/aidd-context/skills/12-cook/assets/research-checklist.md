# Research checklist

A pass is done only when every item clears. Never draft from memory alone.

- [ ] **Fill gaps** — cover what the starting list missed.
- [ ] **Surface unknowns** — search past what you already know; assume blind spots exist.
- [ ] **Clear candidate criteria** — every retained item passes `references/research-playbook.md`, including verification and transferability.
