# Install AIDDy in Codex

Install AIDDy, the Agent Y mascot, as a local pet in the ChatGPT desktop app.

## Why

**AIDDy** reflects task activity with the AI-Driven Development mascot.

**Sprite version 2** selects the supported 11-row animation atlas.

## Steps to install and wake AIDDy

### 1) 🔗 Open the installer

1. In the ChatGPT desktop app, click [Install AIDDy](codex://pets/install?name=AIDDy&imageUrl=https%3A%2F%2Fraw.githubusercontent.com%2Fai-driven-dev%2Fframework%2F1a52770253628062e4e8cbcda1bd062452354c27%2Fassets%2Fpets%2Faiddy-spritesheet.webp&description=Agent%20Y%20for%20AI-Driven%20Development&spriteVersionNumber=2).

Expected: the installer shows the AIDDy name, description, and sprite preview.

### 2) 📦 Install AIDDy

1. Approve the installation.

Expected: **Settings > Pets** lists **AIDDy**.

### 3) 🐾 Select AIDDy

1. Under **Settings > Pets**, choose **AIDDy**.

Expected: AIDDy is marked active.

### 4) ▶️ Wake AIDDy

1. Enter `/pet` in a task.

Expected: AIDDy appears and reacts to task activity.

See the supported [pet install parameters](https://learn.chatgpt.com/docs/reference/commands#pets).
