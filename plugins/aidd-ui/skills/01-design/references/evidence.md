# Interface evidence

## Decision priority

| Priority | Source | Use |
| --- | --- | --- |
| 1 | explicit user requirement | preserve stated intent and constraints |
| 2 | current implementation | establish what exists now |
| 3 | confirmed project memory | recover stable conventions quickly |
| 4 | repeated project pattern | infer a local convention with cited evidence |
| 5 | minimal new decision | fill only the remaining experience gap |

When memory and implementation conflict, use implementation for the current task, report both sources, and request a separate memory refresh rather than editing memory.

## Reuse order

| Order | Existing surface |
| --- | --- |
| 1 | page pattern |
| 2 | composite component |
| 3 | primitive |
| 4 | token |
| 5 | layout convention |

Reuse a satisfying surface. Extend the smallest coherent surface when reuse fails. Create only when no existing surface can express the requirement.
