# 03 - Review

Find actionable improvements across an existing backlog.

## Input

The read model and any project workflow policy.

## Output

Prioritized findings and an optional change set.

## Process

1. **Review.** Apply [backlog review](../references/review.md) to the read model.
2. **Verify.** Delegate semantic readiness checks only for flagged artifacts.
3. **Trace.** Follow completed evidence to affected parents, goals, or durable project learning.
4. **Propose.** Normalize justified corrections with [change set](../references/change-set.md).
5. **Decide.** Continue to authorization only when a change is proposed.

## Test

| Case | Pass |
| --- | --- |
| Reported error | it leads the findings; no semantic review hides it |
| No workflow policy | WIP and age are not evaluated |
| Readiness gap | affected owner and evidence named |
| New completion feedback | each unabsorbed parent, goal, or learning consequence proposed once |
| Healthy backlog | no mutation proposed |
| Review | workspace unchanged |
