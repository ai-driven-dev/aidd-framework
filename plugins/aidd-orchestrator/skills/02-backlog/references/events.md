# Events

| Event | Owner |
| --- | --- |
| Epic create, revise, order, estimate, start, complete, supersede, or cancel | Epic |
| Story slice, revise, estimate, order, start, complete, supersede, or cancel | User Stories |
| Task create, revise, classify, order, estimate, start, complete, supersede, or cancel | Task |
| uncertainty create, investigate, conclude, or resume | Spike |
| Defect report, assess, order, start, complete, supersede, or cancel | Defect |
| intake or duplicate check | Backlog triage, then selected artifact owner |
| backlog health or flow review | Backlog review, then affected artifact owners |
| Epic or Story refinement | Three Amigos, then affected artifact owners |
| completed evidence that changes project knowledge | matching learning capability |
| health or relation repair | affected artifact owners |

Use the project-defined artifact type when it extends this map. Route to the owner. What the event then means for other artifacts is for that owner to state.
