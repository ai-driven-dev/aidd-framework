# Intake

| Observed need | Route |
| --- | --- |
| same outcome, behavior, uncertainty, or mismatch | reuse existing artifact |
| outcome requiring several deliverable slices | Epic |
| one independently deliverable behavior | User Story |
| bounded delivery work without independent user value | Task |
| uncertainty blocking estimation, feasibility, or design | Spike |
| observed behavior differs from expected behavior | Defect |
| active service disruption | incident-response capability |

Preserve the authoritative support, stable source id, and native relations. Ask when the distinction between value, delivery work, unknown, and mismatch is unresolved.
