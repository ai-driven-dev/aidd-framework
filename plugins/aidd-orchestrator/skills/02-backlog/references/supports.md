# Supports

Resolve durable semantics from loaded project memory and current capabilities from each live support.

| Signal | Result |
| --- | --- |
| explicit target | use it when capable |
| existing artifact | preserve its support and identity |
| memory assigns authority | use that support after confirming it exists |
| one capable support remains | select it |
| several remain | ask |
| memory and support conflict | ask; change neither |
| no support exists | offer session or Markdown |

Each artifact and field has one authority. Across supports, keep a stable link or a configured projection, never a second copy. Read technical ids from the live support and verify every write there.

Only a support the project can read is checked for you. Every owner verifies its own writes on any other, and reports what it verified.

A support left unread leaves the model partial: say so, never report it as an empty backlog.
