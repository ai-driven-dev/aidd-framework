# Events

| Event | Owner |
| --- | --- |
| Epic create, revise, start, complete, or cancel | Epic |
| Story slice, revise, estimate, order, start, complete, or cancel | User Stories |
| Task create, revise, classify, order, estimate, start, complete, or cancel | Task |
| uncertainty create, investigate, conclude, or resume | Spike |
| Defect report, assess, order, start, complete, or cancel | Defect |
| intake or duplicate check | Backlog triage, then selected artifact owner |
| backlog health or flow review | Backlog review, then affected artifact owners |
| Epic or Story refinement | Three Amigos, then affected artifact owners |
| Spike conclusion | Spike, then every parent owner |
| Story start, completion, or cancellation | User Stories, then parent Epic |
| Task completion or cancellation | Task, then its parent owner |
| Defect completion | Defect, then affected artifact and goal owners |
| completed evidence that changes project knowledge | matching learning capability |
| health or relation repair | affected artifact owners |

Use the project-defined artifact type when it extends this map. One event may have several consequences, but each field has one owner.
