# Handoffs

Offer the named capability with what was observed, then stop. Never invoke it silently, never write outside a Defect.

| Observed | Capability | Return |
| --- | --- | --- |
| desired new behavior | User Story | one-way; no Defect is created |
| resolution work worth tracking apart | Task | linked to this Defect |
| unknown blocking resolution | Spike | assessment resumes after its outcome |
| active service disruption | incident response | out of backlog |
| no match | none | report what was observed |
