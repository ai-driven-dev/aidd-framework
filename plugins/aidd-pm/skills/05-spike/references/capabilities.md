# Capabilities

Find a capability by the outcome it must produce. Invoke it; never copy or simulate it.

| Need | Use | Required result |
| ---- | --- | --------------- |
| unclear question or decision | a discovery capability | a confirmed question and decision |
| material factual claim | a fact-checking capability | verdicts with sources |
| high-impact conclusion | a challenge capability | findings against the question, bounds, and evidence |
| executable evidence | a matching capability or tool | a documented result from isolated, disposable work |
| unblocked parent | the parent's owner | re-estimate, refine, redesign, or accept risk |
| no match | nothing | report the gap |
