# Investigation

Bound research by decisive evidence, not elapsed time.

| Situation | Next |
| --- | --- |
| new attempt | take the cheapest decisive path; record method, source, and result |
| result unverified or unchallenged | apply the matching capability, then record again |
| decision settled | return the evidence and the status |
| a dependency stops the next check | return `blocked` and name the dependency |
| no viable evidence path | return `inconclusive` |
| next path inside the authorized bounds | attempt again with a changed hypothesis, input, or method |
| next path beyond them | ask to extend or stop before changing the status |
