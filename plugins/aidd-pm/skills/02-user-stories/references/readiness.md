# Readiness

| INVEST | Passes when |
| --- | --- |
| Independent | avoids artificial coupling and names unavoidable dependencies |
| Negotiable | states the need without freezing the solution |
| Valuable | source names an effect beyond the requested behavior |
| Estimable | can be sized when the project requires estimation |
| Small | fits the project's delivery boundary |
| Testable | acceptance is objectively observable |

A Story is `ready` when INVEST passes, acceptance is complete, relations are known, and no blocking question remains. Otherwise it stays `proposed` with its gaps. Persistence does not require readiness.
