# Readiness

| INVEST | Passes when |
| --- | --- |
| Independent | avoids artificial coupling and names unavoidable dependencies |
| Negotiable | states the need without freezing the solution |
| Valuable | source names an effect beyond the requested behavior |
| Estimable | can be sized, or the project does not estimate |
| Small | fits the project's delivery boundary |
| Testable | acceptance is objectively observable |

Acceptance is the Story's own proof: satisfying it is what `done` records. Quality gates the whole team applies belong to the Definition of Done, never here.

A Story is `ready` when INVEST passes, acceptance is complete, relations are known, and no blocking question remains. Otherwise it stays `proposed`: a blocking unknown becomes a Spike, anything else is simply not written yet. Persistence does not require readiness.
