# Ordering

Use only signals supported by the source or project:

| Signal | Effect |
| --- | --- |
| required predecessor | comes before its dependent Story |
| blocked item | remains behind its blocker |
| earlier user value | may move earlier |
| urgent cost or obligation | may move earlier |
| decisive learning or risk reduction | may move earlier |
| unsupported value or urgency | has no ordering weight |

Use the project's method when one exists. Otherwise propose a relative order with reasons and let the user decide. Never manufacture a numeric score.
