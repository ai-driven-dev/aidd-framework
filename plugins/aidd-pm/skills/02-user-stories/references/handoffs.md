# Handoffs

Offer the named capability with what was observed, then stop. Never invoke it silently, never write outside a Story.

| Observed | Capability | Return |
| --- | --- | --- |
| outcome needing several deliverable slices | Epic | one-way; no Story is created |
| work without independent user value | Task | one-way |
| observed product mismatch | Defect | one-way |
| uncertainty blocking readiness | Spike | assessment resumes after its outcome |
| no match | none | report what was observed |
