# Estimation

| Situation | Result |
| --- | --- |
| project defines a scale and comparable completed work exists | propose a relative estimate |
| project defines a scale but evidence is insufficient | ask the team or keep unestimated |
| project memory names no scale | omit the estimate; readiness is unaffected |

Estimation measures expected effort under the team's convention. Keep product value, urgency, and change risk separate. The user or team confirms every estimate.
