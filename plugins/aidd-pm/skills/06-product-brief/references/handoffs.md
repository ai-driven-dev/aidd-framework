# Handoffs

Offer the named capability with what was observed, then stop. Never invoke it silently, never write outside a brief.

| Observed | Capability | Return |
| --- | --- | --- |
| requirements for a settled product | a requirements capability | one-way; no brief is created |
| one outcome requiring several deliverable slices | Epic | one-way; the brief stays its goal |
| one independently deliverable behavior | User Story | one-way |
| observed product mismatch | Defect | one-way |
| no match | none | report what was observed |
