# Discovery Techniques

Choose a lens only when it resolves a live uncertainty.

| Uncertainty | Lens | Useful result |
| --- | --- | --- |
| Motivation or progress | Jobs To Be Done | situation, desired progress, outcome, and current alternative |
| Meaningful user differences | Behavioral personas | evidence-backed groups that can change a product decision |
| Customer value | Value proposition | jobs, pains, gains, and the product bet that addresses them |
| Product success | North Star | an earned metric for recurring user value, with guardrails if needed |
| Opportunity space | Opportunity mapping | desired outcome and evidence-backed opportunities |
| Existing experience | Journey mapping | observed steps, friction, and feedback points |
